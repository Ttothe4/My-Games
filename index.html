Help & Feedback

📧 Send an email

Use this for a bug report, game idea, update request, or anything else about the Game Library.

Email 7famsains@gmail.com

🛠 Game will not open?

Refresh the website, make sure you are online for games that use internet resources, or use the ↗ Open button to launch the game directly in its own tab.

📲 Install the library

On compatible browsers, an Install App button appears at the top. Installing creates an app-style shortcut while still using the same GitHub Pages website.

🐛 Bug report tip

Include the game name, what you clicked, what you expected to happen, and what actually happened.

💡 Update idea tip

Say which game you want changed and describe the new feature. The game's Update Log can be updated when a new version is added to this hub.
